## 主路径（14 步）

### GP-1 登录 → Today
打开 `/teacher/today`。
**必须看到**：
- 下一节课 hero：高二（3）班 · 《导数与函数单调性》 · 10:10 · 距上课倒计时 · 备课完成 70% · 还缺"边界反例 / Exit Ticket"。
- 至少 3 项上课前任务（21 份待批 / 7 人视频未完成 / …），每项带动作按钮。
- 洞察卡："17/46 人连续两次在 a=0 边界失分"，带【加入下节课】【出巩固题】【看依据】。
**FAIL 条件**：出现 `count=`/`recent_count`/`confidence`；任务或洞察无动作按钮；大面积空白。

### GP-2 洞察 → 备课（核心差异化演示）
点击【加入下节课】。
**必须发生**：跳转 `/teacher/prep?lesson_id=…&from=insight:{id}`，目标环节（例题2 之后）高亮，右侧出现建议 diff：
- 建议插入"边界反例 a=0 分类讨论，4 min"，依据引用 17/46 证据，可【看 3 份典型作答】。
**FAIL 条件**：只是跳到备课页顶部；建议无依据；无 diff。

### GP-3 采纳 → 时间线真实变化
点击【采纳到课时】。
**必须发生**：时间线在例题 2 后插入 intervention block；总时长重新平衡仍 ≤45 分钟；若超时提示从哪段压缩。
**FAIL 条件**：采纳后页面无变化；总时长溢出无提示。

### GP-4 编辑环节（结构化编辑器）
点击任一环节【编辑】。
**必须发生**：右侧结构化编辑抽屉打开（目标/师生活动/核心问题/素材/检查理解/时长），支持数学公式预览；保存后时间线更新。
**FAIL 条件**：出现 `window.prompt` / 单行文本框充当编辑器。

### GP-5 确认本节课
点击【确认本节课】。
**必须发生**：lesson_plan artifact 状态 draft → confirmed（有可见状态标记）；产物按钮（PPT/当堂练习/板书）变为可用。
**FAIL 条件**：无确认语义；确认前后页面状态无区别。

### GP-6 生成当堂检测 → 试卷对象
点击【生成当堂练习（3 题）】→ 进入 Assign（蓝图预填 a=0 边界知识点）。
**必须发生**：右侧出现真正试卷：题型分组、每题 stem（公式正确渲染）、知识点、难度、分值、来源；顶部汇总"3 题 / 覆盖 a=0 边界"。
**FAIL 条件**：试卷只有 1 题；裸 `$` 上屏；题数与蓝图不符。

### GP-7 逐题编辑与换题
对第 2 题：编辑分值 → 换一题。
**必须发生**：换题后**仅第 2 题变化**（同知识点/同难度候选），总分与覆盖实时联动；其余题 token 不变。
**FAIL 条件**：换一题触发整卷重生成；总分不联动。

### GP-8 覆盖检查 → 预览学生端 → 发布
**必须发生**：覆盖检查显示知识点勾选与"答案已校验"；【预览学生端】以学生视角展示整卷；【确认并发布】仅在校验全过后可点；发布成功进入 published。
**FAIL 条件**：发布按钮在题数/总分不一致时仍可点；无学生端预览。

### GP-9 学生提交 → 批改队列
（fixture：学生端已产生 21+ 份提交）进入 Grading。
**必须发生**：顶部"《导数周测》· 第 1/21 份"；左作答右建议布局；URL 含 `?submission_item_id=`。
**FAIL 条件**：显示置信度百分比 / `type=rule` / 用下拉框做主导航。

### GP-10 AI 建议 → 教师改分 → 确认并下一份
**必须发生**：右侧建议分 + 逐评分点（✓/!）+ 依据；教师改分后按 Enter【确认并下一份】；进度推进到 2/21；URL 同步为下一份 id；刷新回到同一份。
**FAIL 条件**：确认前写正式成绩；确认后回队首；改分不生效。

### GP-11 批改完成 → 讲评洞察
批完（或批量确认）后。
**必须发生**：出现"本次作业最值得讲的 3 题"（第 4 题 · 17 人错 · 遗漏 a=0 边界），带【加入明天讲评】【生成一个变式】【看典型错误】。
**FAIL 条件**：以"任务结束"收尾无下一步。

### GP-12 学情 → 干预
进入 Classes（高二（3）班 insights）。
**必须发生**：a=0 边界仍是顶部洞察（含 7 人重复名单入口）；每个洞察有动作（布置练习/加入下节课/查看名单）。
**FAIL 条件**：纯图表无动作；数字与全站不一致。

### GP-13 课堂 Session（可与 GP-12 并行验证）
进入 Classroom，选择当前课开始 session。
**必须发生**：头部"高二（3）班 · 导数与单调性 · 10:10–10:55 · 已连接 44/46"；发起检测题后出现实时分布（44 已答 / 27 对 / 选项柱状）；给【展示分布】【讲这道】【推一个变式】；AI 提醒错误模式与昨天作业一致。
**FAIL 条件**：出现"有效期 14399 秒"类工程表达；页面只是一个开关。

### GP-14 闭环回流 → 效果验证
课后（fixture 推进）回到 Today。
**必须发生**：出现"补讲后相似题正确率 54% → 81%，本次补讲有效"类复盘洞察；下一轮备课建议出现在下一节课 hero。
**FAIL 条件**：闭环断头，无效果对比。
