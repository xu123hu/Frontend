## 0. 摘要

**结论速览（4 条）：**

1. **十板块骨架与行业规范高度吻合，但有三个真空缺**。教学过程「教师活动 + 学生活动 + 设计意图」三栏恰好是教资规范与优质课教案的标准写法；但行业必查的「教学重难点」「教材分析（内容解析）」「教法学法/教学手段」在十板块中没有落点，教学目标也未按「核心素养 + 行为动词分层」的课标写法约束。模板的风格标签（探究式/讲练/复习）属自拟，未找到公开对标物。
2. **「只填课题一键出稿」是行业少数派黑盒**。通用 AI PPT（WPS AI、Gamma、Kimi、讯飞智文）已普遍是「先生成大纲 → 用户确认/编辑 → 再生成」两段式；教育垂类普遍收集「教材版本 + 学段 + 章节 + 课型/时长」；国外教师工具表单固定含年级/学科/课题/课标/时长五件套。V3 的 `outline` 事件只作进度展示、不可编辑、无确认点。
3. **「上传个人教案/PPT 当模板」方向正确，行业已验证**：讯飞支持上传教案构建个人知识库智能体；Kimi 支持上传个人 PPT 模板做风格对齐；希沃 AI 备课支持「输入主题或上传教案」生成。建议做**双轨**：内置标准模板库（免费官方资源可冷启动）+ 个人模板提炼，并对上传教案做反套话质量体检。
4. **备课的真实形态是「找资源 → 改资源」而非从零创作**：备课占教师日均 2.98 小时居各项之首；高中数学课堂课件约 82% 来自下载或他人课件、自制仅约 15.6%；公开课与日常课是两套体系（备赛以月计）。「上传往年教案/PPT」正是把教师既有积累数字化，与其现有行为一致；产品定位应为「高质量可改的初稿生成器」。

## 1. 教师真实备课流程与痛点

### 1.1 流程：备课已「课件化」，主路径是「找资源 → 二次修改」

- 备课的实际产出重心已从「写教案」转向「做课件」：艾瑞咨询 × 希沃 2020 年报告指出，教师做课件的参考资料主要有三类——教参配套电子资料、自己/同事积累的课件、平台检索的资料（[报告 PDF](https://pdf.dfcfw.com/pdf/H3_AP202011121428462906_1.pdf)）。

- 商业平台已把「备一节新授课」封装成标准动作：学科网「上好课」按「学段→学科→版本→章节」定位课时，每课时提供课件 + 教学设计详案 + 导学案 + 分层作业资源包；官方描述的课前流程是「下载 → 二次修改适配本班学情 → 打印导学案 → 预设分层作业」，并提醒「原封不动直接用」是常见误区（[学科网实测](https://m.zxxk.com/article/1119159.html)）。

- 学校层面的正规流程叠加了集体备课与「二次备课」（集备后按本班学情调整教学案）；部分学校要求青年教师手写详案。

- 教师对网络资源的需求排序（2015 年调查）：教参类 90.1% > 试题/论文 75.2% > 教案 71.6% > 课件 68%。

### 1.2 时间成本：备课是教师第一重负担

| ------ | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |

### 1.3 课件来源：下载与改用是绝对主流

某高中数学教师群体调查：下载后修改使用 44.44% + 直接使用他人课件 26.67% + 直接下载使用 11.33%，合计约 82%；自制仅 15.56%（[论文收录页，原始出处不可考，中等可信](https://www.docin.com/touch_new/preview_new.do?id=4780422382)）。与希沃大数据（活跃教师人均获取课件 7.1–9.2 份，[报告](https://pdf.dfcfw.com/pdf/H3_AP202011121428462906_1.pdf)）及学科网按教龄分层的描述（新手「照着用」、成熟教师「借鉴+改造」）相互印证。

### 1.4 痛点结构

1. **数学学科特有**：公式排版与几何图形是最高频抱怨（立体图形画歪、矩阵公式错位）；某地调研仅约 25% 教师能独立用 GeoGebra 做动态几何课件，中老年教师普遍畏难新软件（[湖北日报](https://news.hubeidaily.net/pc/c_5666372.html)）。这恰好是 V3 数学编辑内核的强项，应保持为第一卖点。
2. **教案在很大程度上是「检查合规文档」**：多校教案检查制度要求课题/课型/目标/重难点/学情/过程环节齐全/板书设计/反思/二次备课留白——这就是行业「教案模板」的真实出处；教师自述「手抄教案的唯一作用是应付检查」（[半月谈](https://www.xhby.net/content/s65f8e4c1e4b09dde337fcec4.html)）。
3. **公开课与日常课两套体系**：公开课核心是「出彩」，日常课核心是「落地有效」；AI 平台不宜用同一档产品覆盖两者，公开课模式（精细设计 + 磨课迭代）适合单独分层。

### 1.5 对产品的启示

- 产品定位是「高质量、可逐块修改的初稿生成器」，不是「替老师创作」——与红线 R5 一致。

- 「上传往年教案/PPT」不是新发明，而是把老师本来就在做的「攒资料、改课件」数字化进平台，行为迁移成本低。

- 「检查合规版教案」是一键生成的刚需场景：目标/重难点/学情/环节齐全/板书/反思栏目一个不能少。

## 2. 行业教案模板标准与 V3 十板块对照

### 2.1 通用栏目（四类来源交叉验证一致）

- **教资规范版（最简四块）**：教学目标、教学重难点、教学过程（复习导入 → 讲授新课〔初步感知/小组讨论/总结归纳〕→ 巩固练习 → 课堂小结 → 布置作业），每个环节写「教师活动 + 学生活动 + 设计意图」（[教资教案模板](https://blog.csdn.net/qq_34438969/article/details/129379121)）。

- **师范教学设计版**：教材分析、学情分析、教学目标、重难点、教具准备、教法学法、教学过程（[华图](https://m.jl.huatu.com/2022/0403/2190455.html)）。

- **人教社官方体例（《高中数学教科书教学设计与指导》）**：单元内容及其解析 → 单元目标及其解析 → 单元教学问题诊断（难点）→ 支持条件 → 课时设计（内容/目标/重难点/过程/目标检测）（[体例](https://www.docin.com/touch_new/preview_new.do?id=5018913451)）。

- **学校检查制度版（「模板」的真实出处）**：以高青燕园学校为例——课时序号、课题、课型、教学内容、教学目标、重点难点、教学方式、教具、教学过程（复习引入/新知探究/巩固练习/归纳小结/布置作业）、板书设计、教后反思，「新课必须是详案」（[高青](http://www.gaoqing.gov.cn/gongkai/site_gqxjyhtyj/channel_62c6a33037f1f0bd2f27c105/doc_632bcefe8ab715d9224eec7b.html) · [东营晨阳](http://www.dyedz.gov.cn/art/2025/5/30/art_285140_10355736.html) · [青岛升平路](http://www.qdlc.gov.cn/sygk/jy/xx/qdsplxx/newxxgk_146506/gzzd_146510/202302/t20230220_6990422.shtml)）。

### 2.2 范文实录：《导数的概念》

抓取到的完整优质课范文（人教A选修Ⅱ/北师大版）结构：课题信息 → 一、教材分析（内容定位/在高中数学中的地位）→ 二、学情分析（有利/不利因素）→ 三、目标分析（三维目标 + 重难点 + **难点突破策略**：从瞬时速度、切线斜率两个模型类比归纳）→ 四、教法学法 + 教学手段 → 五、教学过程（表格：环节/内容/师生活动/设计意图；「复习引入·提出问题 → 类比探索·形成概念」，含例1：求 y=x² 在某点处的导数）→ 巩固/小结/作业（[范文全文](https://www.renjiaoshe.com/beishidagaozhongshuxue/xuanxiu1/489379.html)）。

同一课题的 2025–2026 学年新课标写法则按核心素养逐条表述：「数学抽象：经历由高台跳水抽象出导数概念的过程……直观想象与逻辑推理：深刻体会极限逼近思想……」（[学科网](https://m.zxxk.com/soft/57075775.html)）。

### 2.3 教学目标写法：三维目标 → 核心素养 + 行为动词

- 2017 版课标（2020 修订）确立六大核心素养：数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析（[王尚志访谈](https://www.ictr.edu.cn/periodicals/jing/detail/618.html) · [人民网](http://edu.people.com.cn/n1/2020/1124/c1053-31942152.html)）。

- 知识技能目标按「了解 → 理解 → 掌握（→ 运用）」行为动词分层；过程目标用「经历/体验/感悟/探索」（[动词分层](https://www.xy8z.com/grade/three/2016/1025/467.html)）。

- 素养目标须与素养水平对应（水平 1–3 各有动词表，如数学抽象 L1「抽象、归纳、了解、感悟」（[辽师大学报](https://jykx.lnnu.edu.cn/CN/Y2021/V37/I3/52)））。

### 2.4 V3 十板块对照表

| V3 板块   | 行业对应栏目             | 判定                       |
| ------- | ------------------ | ------------------------ |
| 课标与学情   | 学情分析（+课标依据）        | 吻合；建议扩入「教材分析/内容解析」       |
| 教学目标    | 教学目标               | 吻合；**需补核心素养 + 行为动词写法规范** |
| （无）     | **教学重难点（+难点突破策略）** | **缺失。学校检查必查项，必须补**       |
| （无）     | 教材分析（内容解析/地位作用）    | 缺失，建议并入信息头               |
| （无）     | 教法学法/教学手段          | 缺失，建议作模板固定字段             |
| 复习引入    | 复习导入               | 吻合                       |
| 新知探究    | 新知探究/概念形成          | 吻合                       |
| 例题精讲    | 例题讲解               | 吻合                       |
| 变式训练    | 巩固练习               | 吻合                       |
| 易错辨析    | （行业无常设栏目）          | 超出常规的特色板块，公开课亮点，保留       |
| 课堂小结与检测 | 课堂小结 + 目标检测        | 吻合                       |
| 分层作业    | 布置作业/分层作业          | 吻合                       |
| 教学反思与板书 | 板书设计 + 教学反思        | 吻合（反思为课后补写）              |

另：十板块默认时长合计 48 分钟，超出高中一节课 40–45 分钟，应按课型给出两套时长预算。

**结论**：十板块不是「无依据的自拟结构」——骨架站得住；真正的问题是 ① 缺「教学重难点」等必查栏目；② 目标/环节文案写法没有行业规范约束（这正是 AI 容易写成套话的地方）；③ 内置模板仅 3 套自拟 style\_tag，缺「对标真实优秀教案」的标准模板库。

### 2.5 模板校准建议（低改动量）

1. 不动十板块骨架：「教学目标」板块增加「教学重难点」字段组（重点/难点/突破策略）；「课标与学情」扩为「教材分析 · 学情」（各加一个文本槽）。
2. 教学目标生成改为双线模板：知识技能线（行为动词分层）+ 素养线（六大素养逐条对应活动）——直接写进生成器约束与反套话词表。
3. 新增「标准模板库」：以本次调研范文结构为蓝本做 3 套新授课模板（概念课/定理公式课/习题复习课），用国家平台与优质课范文做 few-shot 素材（见 §4）。

### 3.3 国外教师工具：表单五件套

## 5. 改造建议（V3.1 增量设计，映射现有契约）

### 5.1 生成入口：把「一句话」换成「五件套 + 补充」

`PrepView` 新建表单（保留现有班级/课型/模板选择）增加：

| 字段        | 类型                    | 说明                            |
| --------- | --------------------- | ----------------------------- |
| 教材版本 + 章节 | 级联选择                  | 数据源可先沿用 kp-tree 三级树（模块→章→知识点） |
| 课时信息      | 课时序号 + 时长（40/45 min）  | 决定各环节时长预算（解决默认 48 分钟超时问题）     |
| 重难点（选填）   | 文本                    | 「想强调什么」的显式入口，AI 优先围绕它组织       |
| 补充要求（选填）  | 文本                    | 例：结合某情境导入 / 只讲第 1 课时 / 多用几何直观 |
| 例题来源      | 题库勾选或「AI 配题」          | 复用 `V3AttachedExample` 挂例题链路  |
| 教案模板      | 标准 3 套 + 「我的模板」（上传提炼） | 见 §5.3                        |

契约改动：`generation/plan` 请求体扩 `textbook_version / chapter / duration / key_points? / extra_requirements? / example_source?`；全部可空、向后兼容。

### 5.2 大纲确认点：消灭流程性黑盒（P0，收益最大）

现链路 `meta → outline → section×n → done` 中 `outline` 不可停留。两个方案：

- **方案 A（推荐，接口两段式）**：`POST generation/plan/outline` 返回大纲（环节名/时长/目标草案/例题建议）→ 前端展示**可编辑大纲**（增删环节、调时长、改目标）→ 教师点「开始逐板块起草」→ `POST generation/plan` 携带确认后的大纲。改动小、断线稳、可离线测试。

- **方案 B（任务流中断恢复）**：沿用 `BACKEND_GUIDE §3.10` 的 langgraph `interrupt` 映射——outline 后任务置 `needs_confirmation`，教师编辑大纲后 `resume`。适合后续把课件生成、讲评生成统一进同一状态机。

红线对照：R4「生成前先看见」在原型里只落了「模板小样」，没落「大纲确认」——这是本次最需要补的洞。

### 5.3 首启引导 + 上传个人教案/PPT 当模板（P1 立项）

**流程（首次进入备课中心时触发，可跳过）：**

1. 引导页：「上传 1–5 份你最满意的教案或课件（Word/PDF/PPT/拍照均可）」——多份、分批均可。
2. 解析：复用后端既有文档解析栈（MinerU/docling + `photo-ingest` 识别链路，见 `BACKEND_GUIDE §3.3`）。
3. **质量体检（差异化关键）**：反套话检测（复用 `cliche.ts` 规则）+ 栏目完整度检查 → 输出「哪些环节齐全 / 哪些是套话」，帮老师挑出真正值得当模板的 1–3 份；低分件明确提示「不建议作为模板」。
4. 结构提炼 → 生成「我的教案模板」：环节顺序、三栏写法风格、例题密度、语言风格画像；教师确认/微调后入库。
5. 之后每次生成默认带出「我的模板」，可切换标准模板；多模板按课型自动推荐。
6. 第二期（P2）：上传件进入个人 RAG 知识库，生成时按相似课题检索教师历史教案做 few-shot——即「讯飞个人知识库」模式。

**契约增量：**

- `POST /catalog/plan-templates/import`（multipart 多文件 → 返回解析任务 task\_id）

- `V3LessonTemplate` 扩展：`source: 'builtin' | 'teacher_upload'`、`boards_schema`（环节结构）、`style_profile?`、`quality_report?`

- `catalog/lesson-templates` 返回 builtin + personal 合并列表（前端模板卡加「我的」角标）

**必须防的坑：**

1. **老师上传的教案未必合格**（可能也是网上下载的套话教案）→ 质量体检前置 + 引导「只挑最满意的 1–3 份」。
2. **新教师没有历史教案** → 内置标准模板库（§2.5）兜底，个性化不能是唯一路径。
3. **合规**：上传件可能含学生姓名/成绩，引导页提示脱敏；解析在服务端完成，不留原始件除非教师勾选存入资源库。

### 5.4 课件侧同构修复

主题生成（`generation/deck`）同样补齐：章节 → 知识点**勾选（多选）** → 生成策略（每知识点一组页 / 合并为一份课件）→ 页数预算 → 模板选择 → **大纲（页面结构）确认** → 逐页草稿 diff 采纳（已有）。消除「一个知识点丢给 AI 就定生死」的黑盒感，与「拍照生成」的配置链路（拍什么/生成模式/模板）对齐。

### 5.5 优先级

| 优先级 | 事项                              | 理由                       |
| --- | ------------------------------- | ------------------------ |
| P0  | 教案表单五件套 + 大纲确认点（方案 A）           | 改动小、直接回应「黑盒」；对齐行业两段式共识   |
| P0  | 教案模板校准：重难点字段 + 目标写法规范 + 反套话词表扩充 | 模板可信度是产品根基               |
| P1  | 首启引导 + 上传模板（结构级）                | 行业已验证、与教师既有行为一致、形成个人资产壁垒 |
| P2  | 个人 RAG 风格库；国家平台资源导入助手；公开课模式     | 增强项，依赖 P1 的数据积累          |
