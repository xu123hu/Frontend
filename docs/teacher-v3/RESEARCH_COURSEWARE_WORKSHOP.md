## 1. 教师制作 PPT 课件的真实链路（复用 + 增补）

- **主路径是"改"不是"创"**：高中数学课堂课件约 82% 来自下载/他人课件修改（下载后修改 44.4% + 直接用他人 26.7% + 直接下载 11.3%），自制仅 15.6%（`RESEARCH_LESSON_PREP.md` §1.3）。
- **数学学科两大特有负担**：公式排版与几何图形（立体图形画歪、公式错位是最高频抱怨；仅约 25% 教师能独立用 GeoGebra）——课件工坊的核心价值锚点是"公式与图形结构化可编辑"。
- **对 AI 生成 PPT 的接受前提**：行业两段式共识——**先生成大纲 → 用户确认/编辑 → 再生成**（WPS AI 官方三步走、Kimi PPT、讯飞智文均如此）；生成后逐页/逐环节可编辑是标配。

## 2. AI PPT 平台的大纲确认步骤怎么做（本轮重点调研）

### 2.1 Gamma：逐页卡片大纲 = 行业标杆（多来源教程互相印证）

Gamma 的生成流固定为：输入提示词（可指定页数/受众/要点）→ **点击 Generate outline 先出大纲** → **逐页卡片（card-by-card）展示每页的建议标题 + 要点** → 用户可**拖拽排序、改标题、删除页、点 + 新增页** → 确认后**再选主题**（视觉画廊，即时预览）→ 约 30 秒生成整份。

关键设计特征（与我们的差距对照）：
1. **大纲页展示的是 AI 写好的标题与要点**，不是空输入框——用户的工作是"审 + 改"，不是"填"。
2. **每页是卡片，不是表单行**：卡片里能看到内容（标题 + bullets 预览），编辑是就地（点进去改）而非永远暴露的下拉框。
3. 排序/增删是一级操作（拖拽手柄、+ 按钮、删除按钮直接可见）。
4. **大纲确认在前、模板选择在后**，两步分开，模板页带实时预览。

来源：MindStudio《How to Use Gamma AI: Step-by-Step Tutorial》（"Before Gamma builds the full presentation, it shows you a draft outline… Reorder slides by dragging them / Rename slide titles / Delete slides / Add new slides by clicking +"）；AI Daily123《How Gamma AI Creates Full Presentations From a Single Prompt》（"Gamma presents a card-by-card outline. Each card shows a proposed title and bullet points"）；EdrawMind《Gamma AI Review 2026》（"Gamma generated an outline instantly with a title and bullets for each card. I dragged a prep step earlier"）；HowAIWorks 工具页。

### 2.2 Kimi PPT（功能页实拍，2026-09-06）

官网功能页自述流程：**选择输入方式（描述需求 / 上传文档 / 粘贴链接）→ AI 生成大纲 → 选择模板（画廊展示模板缩略与配色）→ 生成 → 可完全编辑的 PPT**。页面中部直接展示"模板选择时的候选界面"（一排模板缩略卡）与"结构化页面"概念（封面页/目录页/章节页/内容页分级）。与既有调研一致（`RESEARCH_LESSON_PREP.md` §3.1：先生成结构化大纲、逐元素可编辑）。

### 2.3 WPS AI / 讯飞智文 / 希沃（复用既有调研）

- WPS AI 官方三步走：AI 先生成大纲 → **确认或重新生成** → 选模板生成。
- 讯飞智文：生成大纲要点 → **选模板配色** → 生成。
- 希沃 AI 备课四步：设定目标（可调）→ 生成大纲（**可修改子主题**）→ 生成课件与教学设计 → 保存。

**结论：全部主流平台都是"大纲先出、可编辑、再模板"三段结构，没有一家在确认大纲步骤让用户填空白表单。**

## 3. 拍照出课件 / 拍照录题的做法（本轮重点调研）

市面上没有"拍照 → 直接出课件"的成熟对位产品，但"拍照 → 识别 → 确认 → 应用"的链路在教育工具中高度成熟：

| 产品 | 流程 | 可借鉴 |
| --- | --- | --- |
| 刷刷题"拍一拍"录题 | 对准题目拍照 → OCR 约 3 秒 → **自动识别题目内容、选项、答案及解析（结构化）** → 确认入库 | 识别输出是**结构化结果预览**（题干/选项/答案分区），供确认 |
| 课堂派答题卡 | 拍照上传 → 点"识别校准" → **界面自动高亮所有已识别区域** → 对识别错误项**逐项点击修正** → 保存校准同步 | **原图对照 + 识别区域高亮 + 逐项修正**；先确认再入库，绝不静默采用 |
| OCRAutoScore 智能阅卷 | 上传试卷图片 → 识别 → **教师查看并修正识别结果** → 生成评分 | 识别置信度与人工校对是必备环节 |

**推论**：我们的拍照出课件缺的正是"识别确认"页——上传照片后应先展示"原图 + 识别出的题干/解答结构 + 置信度"，教师逐项校对后才能进入生成；而"识别范围/生成模式/字号档"应压缩为紧凑分段控件，字号与边注归入模板页统一设置（行业在模板步带预览与全局设置）。

## 4. 模板选择的行业做法

- **时机**：统一在大纲确认之后（Gamma/Kimi/WPS/讯飞智文一致）。
- **形态**：模板画廊（缩略图 + 名称 + 适用场景 + 配色点）+ **实时预览**（选中后看封面/内页效果）+ 应用设置（Gamma 的主题卡即时换肤；Kimi 模板卡含配色缩略）。
- **推论**：现状把"风格"放在首页表单、字号/边注放在拍照流程第三步、模板又单独一步——应合并为**一个模板页**：画廊选风格 + 实时预览 + 字号档/边注/应用范围统一在此设置。

## 5. 重设计方案（V4 信息架构）

### 5.1 统一流程（所有入口收敛到同一条主链）

```
入口（首页一句话 / 拍照出课件 / 教案直通 / 课件改编）
   ↓
① 需求与材料（首页 AI 输入即此步，不再单独页）
   ↓
② 大纲确认与编辑 —— AI 生成逐页卡片大纲（标题+要点），可拖拽/改写/增删/单页重写
   ↓
③ 模板选择 —— 画廊 + 实时预览 + 字号档/边注/应用范围统一设置
   ↓
④ 逐页生成（可后台）→ ⑤ 编辑器（公式键盘与绘图收进右下角 AI 工具球）
```

### 5.2 七个页面的设计要点

| 页面 | 核心改动 |
| --- | --- |
| **课件工坊首页** | AI 输入优先：辉光大输入框 + 能力 chips（生成新课件/拍照出课件/教案直通/课件改编）+ 教学上下文胶囊（章节/班级/课型/风格收纳为胶囊，更多设置折叠）+ 三入口卡 + 我的课件 + 今日授课压缩条 |
| **大纲确认与编辑** | 推翻表单：展示 AI 写好的逐页卡片（页码 + 类型 tag + 标题 + 要点预览 + 时长 + 配图/题源 chip），拖拽排序、就地编辑、单页 AI 重写、+ 添加页；顶部统计 + 自然语言调整条 + 重新生成 |
| **模板选择（统一页）** | 左侧模板画廊 6 卡（迷你预览 + 名称 + 适用 + 色板），右侧实时预览面板：应用范围/字号档/边注模式全部收拢于此，底部"开始生成（N 页 · 预计 X 秒）" |
| **拍照出课件** | 新增"识别确认"步：原图缩略 + 识别出的题干/解答结构 + 置信度徽章 + 知识点建议，逐项可改；识别范围/生成模式压成分段控件两行；字号与边注移入模板页 |
| **教案直通** | 选教案卡（课型/环节数/章节匹配）+ "环节 → 页面映射"预览（AI 建议映射，可调每环节页数）→ 下一步进大纲确认而非直接模板 |
| **生成中** | 逐页进度：左列大纲各页状态（✓/生成中/排队），中央当前页预览（骨架屏），进度条 + 后台生成/取消 |
| **课件编辑器** | 删除底部"公式键盘/绘图工作台"常驻 dock；公式键盘改为工具栏按钮唤起的浮层；绘图工具与公式编辑收进右下角 AI 工具球（既有悬浮球菜单：资源推荐/绘图工具/公式编辑/拍照上传）；画布恢复最大空间 |

### 5.3 红线与体验守则（沿用）

- AI 只出草稿，教师确认后生效（每页保留红线徽章或等价提示）。
- 识别/生成结果必须经教师校对才入库/定稿（拍照流程的"识别确认"页即此红线的载体）。
- 公式/图形结构化存储，保持可编辑（属性面板 + 悬浮球工具链）。
