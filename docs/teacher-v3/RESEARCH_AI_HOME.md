## 0. 摘要

**背景**：现版「今日工作台」（V3 课程表 + 待办 + 班级成绩速览）以"管理任务"为中心，AI 只是一个悬浮按钮，背离"AI 智能体"的产品初衷。本次调研回答：高中数学教师备课的真实链路是什么、其他教师助教平台的 AI 首页怎么布局、我们的 AI 主首页应该长什么样。

**结论速览（4 条）：**

1. **备课的真实链路是"找资源 → 改资源"，且 70% 时间是机械劳动**。教师日均备课 2.98 小时居各项之首；高中数学课堂课件约 82% 来自下载/他人课件修改，自制仅 15.6%。AI 首页的定位应是"高质量可改初稿的一句话入口"，而非功能导航站。
2. **AI 原生产品的首页共识是"一个大输入框 + 能力收纳进输入框"**。豆包把 PPT 生成/帮我写作/录音转写等技能做成输入框内的一排 chips；Kimi 极简到"单输入框 + 一排能力胶囊 + 快速/进阶模式切换"；MagicSchool 采用"对话工作台 + All Tools 结构化工具页"双轨。没有一家把"课程表/待办看板"当首页主体。
3. **教育垂类普遍要求"五件套"输入**（教材版本 + 学段 + 章节 + 课型 + 时长），并采用"大纲先生成、用户确认再成稿"的两段式。纯对话式对教师 Prompt 能力要求过高——71.4% 的教师"说不清需求"，需要推荐提示词与引导式配置兜底。
4. **AI 管家的差异化在"上下文感知 + 动作确认"**。教师走到哪 AI 知道哪（当前班级/章节/课件），主动给出今日摘要；所有写操作（入库/生成/跳转）必须经教师确认。这应是 AI 主首页区别于通用 AI 聊天的核心体验。

## 1. 高中数学教师备课教案的真实链路

### 1.1 链路（8 环节）与时间分配

```
课标研读 → 教材分析 → 学情分析 → 资料搜集 → 教学设计 → 课件制作 → 选题组题 → 复盘调整
```

单节新授课备课 2–3 小时：找资源 60–90min（35–40%）＞ 甄别资源 30–45min ＞ 教学设计 40–50min ＞ 课件制作与排版 30–40min ＞ 选题组题 20–30min。**70% 的时间花在"找资源 + 调格式 + 筛题目"等机械劳动上。**

### 1.2 关键行为特征

| 特征 | 证据 | 对首页设计的含义 |
| --- | --- | --- |
| 主路径是"找资源 → 二次修改" | 高中数学课件 82% 来自下载/他人课件修改（44.4% 下载后修改 + 26.7% 直接用他人 + 11.3% 直接下载） | 入口必须支持"上传往年教案/PPT"与"从教材章节开始"两条冷启动路径 |
| 教案很大程度是"检查合规文档" | 多校教案检查要求课题/课型/目标/重难点/学情/环节齐全/板书/反思，缺一项不合格 | 生成物要强调"栏目齐全、规范合规"，最近列表中体现教案/课件/题目多类型产物 |
| 输入"五件套"是行业共识 | 希沃（课型+主题或上传教案）、学科网小博士（版本+章节+对象+环节+字数）、MagicSchool（年级+学科+课题+课标+时长） | 输入框下方常驻"教材版本/章节/班级/课型/时长"上下文胶囊，降低描述负担 |
| 两段式生成（大纲确认 → 成稿） | WPS AI/Kimi PPT/讯飞智文均"先生成大纲 → 确认/编辑 → 再生成" | 首页只负责"发起任务"，生成过程进入带确认点的工作流，不在首页堆生成状态 |
| 数学学科特有痛点 | 公式排版与几何图形是最高频抱怨；仅约 25% 教师能独立用 GeoGebra | 能力入口要突出"公式/图形可直接编辑"的数学专业度 |

### 1.3 教师对 AI 的期待排序

智能组卷/出题（最高）＞ 课件制作（减少排版）＞ 精准资源搜索 ＞ 一键生成规范教案 ＞ 分层作业设计 ＞ 学情与易错点分析。**关键障碍：71.4% 的教师"说不清需求"（不会写 Prompt），69.3% 需要人工修正 AI 产出** —— 首页必须用"推荐提示词 + 引导式表单"代替"自由发挥的聊天框"。

## 2. 教师助教智能体平台的主页布局调研

### 2.1 通用 AI 原生首页（实拍截图验证，2026-09）

| 产品 | 首页布局 | 可借鉴要点 |
| --- | --- | --- |
| **豆包**（doubao.com/chat） | 左侧窄栏（新任务/新对话/最近）+ 中央大标题"有什么我能帮你的吗？" + 对话/工作模式切换 + "为你推荐"提示词堆叠 + 底部大输入框，**输入框内一排能力 chips：对话/PPT 生成/图像生成/帮我写作/视频生成/深入研究/录音转写/更多**，右侧语音/发送 | ① 能力入口收纳进输入框而非铺满页面；② "为你推荐"提示词直接可点；③ 欢迎语是"开放提问"而非固定功能 |
| **Kimi**（kimi.com） | 极简单屏：Logo + 单输入框（placeholder"尽管问，或做个 Agent 任务"）+ 快速/进阶模式 + 输入框下一排能力胶囊：PPT/集群/深度研究/文档/网站/表格/设计 | ① 输入框是绝对主角；② 能力胶囊即"技能清单"；③ 模式切换（快速/进阶）暗示任务复杂度分级 |
| **MagicSchool**（magicschool.ai，2026-07 改版） | 对话工作台（Raina 聊天球）+ 新版 All Tools 页：Teacher Tools / Student Tools / Workflows 分类 + 搜索/筛选 + **教师可自建工具集合（collections）** | ① 85+ 工具不能平铺在首页，需要"常用收藏"机制；② 对话与工具页双轨，对话负责长尾需求 |

### 2.2 教育垂类平台（官方资料 + 已有调研）

| 平台 | 功能结构 | 首页/入口布局 |
| --- | --- | --- |
| 讯飞星火教师助手 | AI 对话、教案生成、课件生成、素材生成、搜题组卷、智能体中心六大功能；支持上传教案构建个人知识库 | 对话式入口 + 功能中心；"一句话生成精品教案/成套课件/智能选题组卷"是主宣传路径 |
| 希沃 AI 备课 | 四步：设定目标 → 生成大纲（可改）→ 生成课件与教学设计 → 保存分享 | 白板编辑三栏式（左页面 + 中画布 + 右属性/AI），备课是流程向导而非自由对话 |
| 学科网 AI 小博士 | 版本+章节+教学对象+环节+字数+特殊要求 → 完整教案 → 续生成 PPT | 表单引导式入口，教材版本/章节是第一选择器 |
| ClassIn X | 课堂 AI 语音助手，自然语言指令触达 43 种授课工具 | 指令 → 工具调用的"AI 操作平台"形态，写操作有确认边界 |

### 2.3 布局模式总结（与本研究 `ai-lesson-planning-research.md` 互相印证）

1. **经典对话三栏式**（豆包爱学/学科网小博士）：左导航 + 中对话 + 底输入 —— AI 原生产品的默认解。
2. **能力橱窗式**（豆包首页/Kimi）：欢迎语 + 一排技能入口 + 输入框 —— 适合"多能力智能体"做品牌化首页。
3. **工具矩阵式**（MagicSchool）：对话球 + 结构化工具页 —— 工具数量多时的组织方案。
4. **流程向导式**（希沃/学科网）：表单五件套 → 分段生成 —— 教育垂类保证首次生成质量的最优解。
5. **教师偏好侧边栏 AI**（LessonPlanner.ai 研究）：编辑场景中 AI 以 sidebar 存在；但**首页**作为任务发起处，对话/输入框居中是全行业共识。

## 3. AI 主首页设计决策（调研结论 → 设计映射）

| # | 调研结论 | 新首页设计元素 |
| --- | --- | --- |
| D1 | AI 原生首页 = 欢迎语 + 大输入框（豆包/Kimi 共识） | 主视觉从"课程表看板"换成居中欢迎语 + 辉光输入框；标题从"今天想备什么课"升级为"今天想让我做点什么"（覆盖备课/PPT/入库/组卷全能力） |
| D2 | 能力入口收纳进输入框（豆包 chips 模式） | 输入框内下沿放能力 chips：备课教案 / 生成课件 PPT / 题目入库 / 智能组卷 / 批改作业 / 语音公式 / 更多 |
| D3 | 教育垂类五件套输入（希沃/学科网/MagicSchool） | 输入框下方常驻上下文胶囊：人教A版·选修一 ▾ / 第2章 圆锥曲线 ▾ / 高二(5)班 ▾ / 新授课 ▾ / 40分钟 ▾ |
| D4 | 71.4% 教师"说不清需求" | "为你推荐"区给出 3 条可点击的真实任务提示词（备课/入库/组卷各一） |
| D5 | 教师期待排序（组卷/课件/入库为高频） | 四张能力卡：备课教案、生成课件 PPT、题目入库、智能组卷（图标色调延续原首页四色系统） |
| D6 | AI 管家"上下文感知 + 主动服务"（RESEARCH_AI_BUTLER L4） | "今日教学"压缩为一条 AI 摘要条（3 节课时间轴 + 待办胶囊），保留旧工作台有用的上下文但不再占满首屏 |
| D7 | 教师多类型产物（教案/课件/题目）与"继续备课"刚需 | "最近工作"改为多类型产物流（教案/课件/入库记录），带筛选 chips 与草稿/完成状态 |
| D8 | 写操作必须教师确认（红线 R5/HITL） | 首页所有卡片/胶囊只做"任务发起"，生成与入库进入带确认点的工作流；悬浮 AI 管家保留 |

**信息架构总览**（自上而下）：顶部导航（延续原样式）→ 上下文问候 → 主输入框（含能力 chips）→ 教学上下文胶囊 → 为你推荐 → AI 能力矩阵（4 卡）→ 今日教学摘要条 → 最近工作（多类型产物流）→ 悬浮 AI 管家。
