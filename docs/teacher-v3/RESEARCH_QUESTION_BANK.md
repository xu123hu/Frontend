## 0. 摘要

1. **现状核查：扫描入库已经是「拍照 → 图片原样入库」双轨设计**。`QuizView.vue` 扫描入库弹层提供两种模式：「图片题型原样入库（保留扫描原图作题干，不强制识别）」与「识别成结构题（走识别链路，进入可编辑的公式题干）」，入库时必选知识点归属，图片题照常可选入试卷（红线 R14）。这正是"避免转换出错"的诉求——原样入库全程不做 OCR/公式转换。**唯一缺口：题库没有独立入口**，目前内嵌在组卷中心（路由 `/teacher-v3/quiz` 标题即"组卷中心"），侧边栏 8 项无「题库」。
2. **行业对标：题库管理共性 = 一棵「版本→章节→知识点」树 + 多维标签横切 + 自建沉淀夹**。组卷网/学科网按「章节+知识点双树、题型/难度/分类/年份/地区/学期」筛选，数理化支持按"解题方法"选题；菁优网有校本题库/卷库/组卷库/错题库四件套与"自编题、改编题、错题集、微专题"归档；自建题库主流形态是校级（批量导题+逐题补标签+共享教研组），个人级收藏夹少见。「图片题原样保存」未见于头部公开产品（行业主流是 OCR 识别匹配原题），但开源题库「题干文本 + 图片附件」并存、图片题靠标签与多模态索引检索有据可依——**原样入库作为兼容路径站得住，识别转结构应保留为推荐升级路径**。
3. **例题来源：双轨制**。优先从题库按「知识点+难度」检索挂入（`V3AttachedExample` 链路已在）；AI 配题兜底，且配题时先检索题库相似题做参考。题库被挂入教案/试卷的次数可作为热信号反哺排序。
4. **知识库飞轮：方向正确，但必须三档分层**。个人私有（可行，讯飞/WPS/腾讯 ima 先例成熟）→ 教研组共享（需权限+查重审核）→ 平台级复用/转售（侵权判例+刑事案例，不可行）。"越用越聪明"最安全的实现是**行为飞轮**（采纳率/修改/评分 → 质量分 → 检索加权），而非内容本体跨用户复用。

## 1. 现状核查（代码与规格证据）

- 规格依据：`REQUIREMENTS_SPEC.md` §7.2 扫描入库（R14：扫描入库即题库永久资产，来源标「拍照入库」）。
- 代码证据（`QuizView.vue`）：「＋ 扫描入库」弹层 → 拖/选图或示例题图（扫描增强先行）→ **入库方式单选**：`image` 模式（hint：保留扫描原图作题干，不强制识别）/ `recognize` 模式（hint：走识别链路，进入可编辑的公式题干）→ 归属知识点下拉（必选，默认取第一个叶节点）→ 确认入库即时进题库列表。
- 图片题型：`q_type='image'`，题干为 `stem_image` 扫描原图，`stem_latex` 仅作说明 caption；列表与 A4 试卷预览渲染原图；照常可选入试卷、来源标「图片题」。
- 现有题目字段（`src/types/teacherV3.ts`）：`q_type: choice/fill/solve`、`difficulty: easy/medium/hard`、`source`（校本/区库/拍照入库）、`kp_path`（分类树路径）、`stem_latex/options/answer`（挂例题模型 `V3AttachedExample`）。
- 缺口清单：
  1. 无独立题库页：题库内嵌于组卷中心，侧边栏无「题库」入口；
  2. 无自建整理容器：无专题夹/收藏夹/错题集；
  3. 标签维度少：缺年份、来源细分（自编/扫描/AI配题），难度为三档枚举（未采用行业得分率口径）；
  4. 题库侧答案/解析编辑入口需在 V3.1 补字段时对齐（挂例题模型已有 `answer`）。

## 2. 对标：行业题库管理结构

### 2.1 公有题库（一棵树 + 多维标签）

| 平台 | 组织与筛选 | 来源 |
| --- | --- | --- |
| 学科网/组卷网 | 章节选题与知识点选题深度结合（章节下再筛知识点）；筛选=类型/题型/难度/分类（典型题·同步题·压轴题）/年份/地区/年级/学期；数理化支持按"解题方法"选题；试题篮="试题购物车" | [组卷网帮助中心](http://kf.zujuan.xkw.com/helper/9) · [组卷网介绍](https://zujuan.xkw.com/atc/product) |
| 菁优网 | 2500 万+试题；双向细目表组卷（知识点/难度/来源/题型）；「遇到好题，拍照即可加入试题篮」 | [菁优官网](https://www.jyeoo.com/introduce/xyhstandard) |
| 区域平台（海南） | 题目带题干/答案/解析/难易度/题类/知识点/学科素养多维标签 | 区域采购平台手册（2025） |

### 2.2 自建题库（沉淀）

- **菁优校本题库**（需学校开通）：校本题库/卷库/组卷库/错题库四件套；教师上传本地文档转换为在线资源多次利用；自编题、改编题、学生错题集、微专题训练分类归档，可设权限共享教研组；学校管理员配置上传审核流程与下载频次（[官网](https://www.jyeoo.com/introduce/xyhstandard) · [阅卷页](https://www.jyeoo.com/yuejuan)）。
- **学科网**：校本题库"自主导题"，定位校内资源共建。
- 个人级"收藏夹"在头部产品中少见，多以试题篮（临时容器）代替——独立"我的题库/专题夹"是我们的差异化空间。

### 2.3 字段模型（一手 SQL：开源题库 open-tiku）

- `textbook` 树：`path_type`（章节/考点同构）、`parent_id`、`path_depth`；`chapter_knowledge` 表做章节↔知识点**多对多关联**（[open_tiku.sql](https://github.com/open-education/open-tiku-api/blob/main/open_tiku.sql)）。
- `question`：题型+题目类型、标签、核心素养、母题/变式关系、来源/原创者/作者、题干（LaTeX）**与 `images`(JSONB) 并存**、纯文本搜索字段 `content_plain`、选项、答案、解析、过程/步骤、审核流（草稿/审核中/通过/拒绝+拒绝原因）；批量导题=上传任务异步处理。
- 印证：题干文本与图片附件并存是题库字段的标准设计——**图片不必强转文字也能成为一等资源**，检索靠标签（+可选 OCR/多模态索引）。

### 2.4 拍照录题与图片题

- 行业主流流程是「拍照 → OCR → 匹配题库原题」（好未来拍照搜题方案、学科网 App 拍照组卷）——照片是**检索入口**而非存储形态。
- 「图片题原样保存、不转文字」未见于头部公开产品；支持性旁证：open-tiku 的 `title+images` 并存设计、「数学题截图+知识点标签」的多模态检索方案。
- **结论**：原样入库作为"识别易出错场景"的兼容路径站得住（靠知识点标签检索、可进试卷）；但组卷排版与全文检索上结构题更强，应把「识别成结构题」保留为**推荐升级路径**（双轨默认值可按场景引导）。

## 3. 题库管理方案（V3.1）

### 3.1 独立题库页

侧边栏新增「题库」`/teacher-v3/bank`：题目列表（分类树筛选+标签筛选）+ 扫描入库 + 自编录入 + 我的专题夹全部迁入；组卷中心改为"选题工作台"（试题篮 + A4 排版预览），从题库取数。API 复用 `catalog/quiz.*`，新增 `catalog/folders.*`。

### 3.2 分类体系

- 主键：维持三级树「模块→章→知识点」（绑定教材版本），入库归属必选（现状已如此）。
- 横切标签：题型（choice/fill/solve/image）、难度（建议对齐行业得分率口径：容易≥0.8 / 适中 0.5–0.8 / 困难<0.5）、来源（拍照入库/自编/AI 配题/校本）、年份（选填）。
- 我的专题夹：自建文件夹（如"圆锥曲线压轴""易错题集"），**跨知识点收集**（题目仍挂树上，夹子存引用）；扫描入库与列表一键入夹；夹可整体进组卷/进教案。对标菁优"微专题/错题集"形态。

### 3.3 字段补齐

`+year?`、`+analysis?`（解析）、`+folder_refs`、难度口径调整（枚举→得分率三档）、来源细分（photo/manual/ai/exam）；`stem_image` 原图路径保持不变（R14）。

### 3.4 图片题的检索

P0 靠知识点标签+题型+难度筛（现状已够用）；P2 可选 OCR 建全文索引（不改变原图展示）；P3 备选多模态向量检索。

### 3.5 消费出口

组卷、教案挂例题（已有 `V3AttachedExample`）、课件生成配题、课堂互动出题、导出 PDF——题库是全平台的内容供给端。

## 4. 例题来源机制（回应「AI 的例题怎么出」）

1. **双轨**：① 题库检索挂入（优先）——生成提纲时按知识点+难度检索题库，给老师勾选；② AI 配题（兜底）——题库无合适题时生成新题，且生成前先检索题库相似题做参考（保持难度与风格一致），新题入库标 `source='ai'`。
2. **热信号**：题目被挂入教案/试卷/课件的次数计数，检索排序加权——题库越用越准，这是质量分的雏形（见 §5.4）。

## 5. 知识库飞轮评估（「上传越多，AI 越聪明」）

### 5.1 实践先例

| 产品 | 能力 |
| --- | --- |
| 讯飞星火教师助手 | 上传教案/教材构建个人知识库智能体，按个人风格生成（[官方](https://edu.iflytek.com/solution/school/teachers-assistant)） |
| 希沃科建库 | 上传试卷 PDF 自动解析、生成讲评课件 |
| 腾讯 ima | 个人库→共享库三级体系、多人共建+权限管理（[架构解析](https://cloud.tencent.com.cn/developer/article/2706885)） |
| WPS 知识库 | 上传文档自动解析索引，AI 问答标注引用来源 |

### 5.2 版权红线（必须先立规矩）

- 学科网用户协议**明确禁止**将学科网资源"上传到其他网站、社区、论坛，或用于算法相关的活动"——老师把下载资源传第三方平台，违约责任在上传者（[学科网用户协议](https://sso.zxxk.com/user/agreement)）。
- 平台注意义务：韩寒诉百度文库案确立对明显侵权内容负有"较高注意义务"、不能只靠通知-删除；中青文诉百度最高法改判、两案共赔 275.9 万（[人民网知识产权频道](http://ip.people.com.cn/n1/2019/0802/c179663-31271821.html)）；倒卖学科网资料已有**刑事判例**（侵犯著作权罪，[中国网教育 2026-07](http://edu.china.com.cn/2026-07/29/content_118624278.shtml)）。
- 教案为职务作品、无特殊约定著作权归教师本人——老师原创教案有权授权平台；但其中嵌入的第三方素材（下载的试卷、他人模板、教材插图）老师无权授权。

### 5.3 三档边界

| 档位 | 可行性 | 前提条件 |
| --- | --- | --- |
| 个人私有（仅本人检索生成） | **高**，先例成熟 | 用户协议（上传者保证权属、责任自担）；内容仅本人可见、不入跨用户检索池；上传环节学生信息脱敏提示；不用于模型训练 |
| 教研组共享 | 中 | 权限受控+可审计；上传查重/指纹拦截明显盗传；通知-删除通道；强制脱敏；不向圈外推荐 |
| 平台级复用/转售 | **低，基本不可行** | 侵权+刑事风险+学生信息扩散；除非完整授权链并经律师专项评估，转售他人版权内容仍不可行 |

### 5.4 行为飞轮（推荐的「越用越聪明」）

沉淀**行为**而非内容本体：AI 草稿采纳率、题目被挂次数、模板使用频次、教师修改幅度 → 个人质量分与偏好画像 → 生成时按质量分加权重排（元数据过滤+重排是 RAG 通行做法）→ 越用越懂这个老师，且零版权风险。质量分维度可参考百度文库评分（浏览/下载/评价/完整度/时效/独创度，0–5 分周期更新）。

### 5.5 隐私

学生姓名+成绩属个人信息；不满 14 周岁属敏感个人信息（需监护人单独同意）；高中生多已超 14 周岁但仍需告知/同意基础。落地：上传环节弹「是否已脱敏学生信息」提示+声明勾选；平台默认不向任何第三方提供上传内容。

### 5.6 落地结论

V3.1 只做「个人知识库」档（上传模板/教案/PPT + 拍照入题库，全部个人私有，承接 `RESEARCH_LESSON_PREP.md` §5.3 的上传链路）；教研组共享后置到具备审核与查重能力之后；「平台大池子」不做。

## 6. 优先级

| 优先级 | 事项 |
| --- | --- |
| P0 | 独立题库页 + 标签/字段补齐 + 我的专题夹（轻量引用式） |
| P0 | 例题双轨：题库检索挂入 + AI 配题（先检索题库） |
| P1 | 个人知识库档（上传教案/PPT→个人模板/素材库）；质量分雏形（被挂次数） |
| P2 | OCR 全文索引/多模态检索；教研组共享（含查重审核）；错题集自动沉淀（接批改数据） |
