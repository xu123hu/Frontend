## 4. Root causes（分层）

| 层 | 病根 |
|---|---|
| 图形模型（根本） | records=笔画（pen/line/circle/polygon/point/text）+ 封闭 preset 图元；无 Point/Segment/Solid/约束/依赖 |
| 数学模型 | 无棱上点/中点/比例/交点/截面；可见性只在 preset 内硬编码 |
| 交互 | 无吸附；标签与对象分离不跟随；无改名/下标；无 per 线虚线；文字工具丢焦点 |
| UI/导出 | 默认函数绘图+全屏网格；导出仅 `<svg>` 丢 HTML 标签层、含坐标网格 |
| AI 层 | 6 个写死模板 + 关键词路由，错配不披露 |

## 5. Research（摘要，全文与来源见 phaseB-research.md）

- JSXGraph（MIT 双许可）：3D 缺的恰好是我们的四项核心（3D 线段交点/截面/遮挡虚线/带标签干净导出）→ 保留其 2D 职责，3D 自建。
- GeoGebra：功能标杆但**商用需付费授权**（收费教师平台=典型商用）→ 法律上排除。
- CindyJS（Apache）：绘制型 3D，无依赖构造 → 排除。
- Three.js/Babylon：只有渲染底座，约束图/HLR/矢量导出全自建=重写引擎 → 不引入。
- NL→构图：GeoBuildBench（中文教材题→DSL）与 GeoChat 先例验证方向，**尚无主流产品落地 = 差异化空位**。

## 6. Decision

**路线 C：自建结构化 3D 几何模型（依赖 DAG）+ 正交轴测 SVG 渲染器 + 确定性构造 DSL**，三输入模式并存：

- Mode 1 手动：骨架 chips + 棱上点/中点/连接/交点/截面/向量工具 + 拖动（棱上点锁棱、顶点拖动变形）+ 视角拖拽旋转/滚轮缩放。
- Mode 2 结构化构造：构造描述（每句一行）→ 确定性解析执行 → ✓/⚠ 回执（未识别如实披露）。
- Mode 3 AI 构图：DSL 算子集即 LLM 输出接口（IFC-GEOM-02 预留），本轮不做假 AI。
- 反作弊自查：无"题19 按钮"；预设=参数化骨架（可拖变形），非静态图；AI 产物=可编辑构造文档非图片；盲测通过证明非针对基准写死。

## 9. 已知边界（诚实清单，均不阻塞教师测试）

1. 标签避让未做：拖动后相邻标签可能重叠（c1-b1-manual-edit.png 中 B/E 轻微重叠）。
2. 截面与棱的交点顶点暂无标签（教材常给截面顶点命名，待补）。
3. 四棱锥底面默认为矩形平行四边形，任意四边形底需手动拖顶点；五/六棱锥骨架未列。
4. 构造描述解析为确定性词表：改写句式（"取 CC1 三等分点"等）未覆盖的会如实进 uncovered；LLM 兜底属 Mode 3（IFC-GEOM-02）。
5. 球的半径是构造时算好的静态数字（球心随依赖移动，但拖动顶点改变棱长后 r 不自动重算）——严格外接需 r 也依赖化。
6. 构造 DSL 不吃尺寸参数（"AB=2 的墙角模型"）：尺寸靠拖动变形，句式解析暂不解析数值。
7. 几何库条目 kind 仍标 'free'（复用现有库表结构，UI 显示"画布"）——正式化时随 IFC-GEOM-01 加 kind。
8. 环境事实：测试期间用户并行改代码触发 HMR 两次重置画布（14:01/14:05）；vite watcher 偶发漏 watch 新建目录内的 ts 文件（touch 可强制）；工作台编辑态不持久（刷新即丢未保存图），建议正式化时加 localStorage 草稿。
