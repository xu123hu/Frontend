## Benchmark 记录

### B1 = 题15：平行六面体 ABCD-A₁B₁C₁D₁，A₁C₁∩B₁D₁=F，连 AF
- 预设路线：立体预设无"平行六面体"，只能放"长方体"近似（正交长方体 ≠ 斜平行六面体，题目图形失真）。
- 手绘路线：可行但每条线凭手感（无顶点吸附）；~18 次交互（含 HMR 重置重放、文字工具丢焦点重试×2）。
- 点 F = 眼睛估的交点（无交点构造）；标签 F 是独立文本对象。
- 修改测试：点 F 附近按下拖动 → 命中的是文字标签（文字命中框大、后加入者优先），标签被拖走、点不动、AF 线不跟随——**无任何依赖，改一处散一处**。
- 导出：SVG 快照含坐标轴+网格+刻度；标签是 HTML div 层，**不在 SVG 里，插入后全部丢失**。

### B2 = 题16：四棱锥 P-ABCD（底面平行四边形），AC∩BD=O，G∈BD 且 BG=2GD，连 PG
- 正 n 棱锥预设 n=4 → 正方形底可接受，但顶点固定叫 S（属性面板无改名，边界说明也承认"顶点标注暂不支持逐点改名字"）；底面顶点序与教材惯例不一致。
- O、G、PG 全靠手点+目测比例；无"棱上比例点/中点"构造；无虚线（对角线应为虚线语义）。
- 6 条记录完成形似图形；导出无标签、带网格。

### B3 = 题19：平行六面体，E=A₁D₁ 中点，F=BC₁∩B₁C，画 DB₁/BE/AF（图中为虚线）
- 手绘 12 条棱（17 条记录，约 19 次手势）：形状可以凑出来（我按投影坐标计算点位），但真实教师手点无计算辅助，误差会很明显。
- E/F 只能目测（无中点构造、无线线交点构造）；三条内部线段必须画虚线——**工具根本没有虚线样式**，全部实线导致图面语义错误（内外前后混成一团）。
- 导出图：无 E/F/A…任何标签 + 坐标网格污染。

### 构图导演探针（题16 自然语言）
- 输入题16 原文 → 关键词命中"正四棱锥过三棱三点作截面"→ 生成 M/N/P 截面方案。**O、G、BG=2GD、PG 全部被静默丢弃**，产出"看似合规实则答非所问"的方案，且无任何"你的要求有 4 条未被采纳"的披露——比诚实 fallback 更伤信任。

## 结论：FUNDAMENTAL FAIL

当前对象模型 = "2D 涂鸦记录（pen/line/circle/polygon/point/text）+ 静态预设图"，不是数学构造模型：

| 层 | 根因 |
|---|---|
| 图形模型 | records 是"画出来的笔画"，无 Point/Segment/Solid/约束/依赖；预设是封闭图元（固定顶点集+固定标签+个别滑杆） |
| 数学模型 | 无棱上点/比例点/中点/交点/截面构造；可见性（虚线）只在预设内部硬编码 |
| 交互 | 无吸附；标签与对象分离（不跟随、命中冲突）；无改名；无 per 线型虚线；文字工具真实点击 2/3 概率丢草稿；无 Redo |
| UI | 默认落在"函数绘图"大坐标系；导出图带网格刻度 |
| 插入链路 | 只序列化 `<svg>`，JSXGraph 文字标签是 HTML div 层 → 插入课件丢所有标注；课件里是 `<img>` 不可再编辑 |
| AI 构图 | 6 个写死模板 + 关键词路由，语义错配无披露 |

纸笔对照：三道题纸笔 30~90 秒/题；平台 5~8 分钟/题且成品数学语义错误（虚实、标注、形状）。平台唯一占优项：存入图形库/结构化重开——但重开编辑后再次插入仍丢标签。
